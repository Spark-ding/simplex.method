# 线性规划单纯形法项目

这是一个使用 C 语言实现的教学型优化算法项目。程序求解标准形式的线性规划：

```text
最大化   c^T x
约束     A x <= b
         x >= 0
```

当前实现使用松弛变量建立初始单纯形表，并使用 Bland 规则选择进基变量，以降低退化问题导致循环的风险。支持：

- 从代码内置示例直接运行
- 从文本文件读取线性规划问题
- 判断最优解和无界情形
- 对负的右端项、空问题和内存错误返回状态码

## 构建与运行

需要 GCC 或兼容 C11 的编译器：

```bash
make
./simplex
```

Windows MinGW 环境可以运行 `mingw32-make`，生成的程序通常为 `simplex.exe`。

内置示例的结果应为：

```text
status: optimal
objective: 9.333333
x1 = 1.333333
x2 = 2.666667
```

## 输入文件格式

第一行是“约束数量 变量数量”；第二行是目标函数系数；之后每行依次给出一行约束的系数和右端项：

```text
2 2
3 2
1 1 4
4 1 8
```

运行：

```bash
./simplex problem.txt
```

该版本假设右端项 `b >= 0`，并且约束均为 `<=`。如果需要处理 `>=`、等式约束或负右端项，可在此基础上增加两阶段单纯形法或 Big-M 法。
